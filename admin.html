🛒 Amazon Gear
A product only renders as a real card once it has a name — unnamed ones stay as the old numbered chips, so filling these in is what upgrades the page. Paste a full Amazon URL and the ASIN is pulled out automatically; add your Associates tag once and new links get built as /dp/ASIN?tag=… so each placement is trackable. Photos stay empty until your Associates account clears the Creators API bar (~10 qualifying sales in 30 days) — the image slot is already wired, so it's a data change when you get there.
